# Astrolab Papers

This directory contains Jupyter notebooks accompanying scientific papers featured on the Stellar Attractor project.

The goal of these notebooks is not to reproduce every detail of the original research, but to explain the underlying ideas and methods in a clear and accessible way. Whenever possible, the notebooks implement simplified or illustrative versions of the algorithms described in the papers.

Each paper is stored in its own directory, named after its arXiv identifier (or another publication ID), and typically contains:

- `README.md` — paper description and links;
- `paper.ipynb` — an interactive Jupyter Notebook with the implementation.

The notebooks are intended for educational purposes and are released as open learning resources.
