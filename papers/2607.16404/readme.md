## About this notebook

This notebook demonstrates the main ideas presented in the paper using a simplified educational implementation.

It is **not** a reproduction of the authors' complete pipeline. Instead, the notebook focuses on illustrating the key concepts, algorithms, and workflow in a form that is easy to understand and experiment with.

Synthetic data are used where appropriate to keep the notebook self-contained and easy to run.

## Contents

- simplified implementation of the proposed method;
- synthetic demonstration data;
- visualizations of the main results;
- explanatory comments.
