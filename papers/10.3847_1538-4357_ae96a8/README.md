## About this notebook

This notebook demonstrates the main ideas presented in the paper using a simplified educational implementation.

It is not a reproduction of the authors’ complete analysis pipeline. Instead, the notebook focuses on illustrating how a nova can become superbright, how an optically thick shocked shell can contribute to its optical luminosity and light curve, and how the resulting behavior differs from that of a normal nova.
